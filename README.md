# OTC Campus Bot

Automated weekly futures market scanner using OTC Campus methodology.

## Features

- **Multi-Asset Analysis:** Commodities, FX futures, indices, stocks
- **Fundamental Bias:** COT, valuation, seasonality
- **Technical Timing:** Supply/demand zone detection
- **Discord Reporting:** Weekly automated reports
- **Free Hosting:** GitHub Actions
